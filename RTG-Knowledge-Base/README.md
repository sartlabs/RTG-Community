
# RedTeamGarage Community

> **Practical offensive security. Real-world red teaming. Community-driven learning.**

Welcome to the **RedTeamGarage (RTG) Community Repository**.

This repository is the central knowledge base for publicly released RTG content, resources, research, cheatsheets, tools, labs and practical offensive security material.

The goal is simple:

**Learn. Build. Break. Understand. Repeat.**

---

## What is RTG?

**RedTeamGarage (RTG)** is a practical offensive security initiative focused on real-world red teaming, penetration testing, security research and hands-on learning.

RTG focuses on practical knowledge rather than purely theoretical security concepts.

## RTG Learning Philosophy

RTG is built around practical learning.

Instead of simply asking:

> "What is this?"

We try to understand:

> "How does it actually work?"

and more importantly:

> "How would this be used in a real environment?"
